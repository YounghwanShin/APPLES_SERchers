# Data Preparation

## 1. Overview

본 프로젝트에서는 미국 드라마 *Friends*의 대화 장면을 활용하여 발화별 감정 점수를 추출하고, 이를 영상의 재생 시점 및 화자 정보와 연결한다.

이를 통해 실제 대화 상황에서 화자별 감정이 어떻게 나타나고 변화하는지 시각적으로 확인할 수 있는 시연 데이터를 구축하는 것을 목표로 한다.

## 2. Scene Selection

시연에 적합한 장면을 선정하기 위해 프렌즈 영상에서 총 10개의 후보 장면을 선정한다.

후보 장면을 모델에 적용해 감정 점수를 추출하고, 다음 기준을 고려하여 최종 시연 장면 3~4개를 선정한다.

- 두 명 이상의 화자가 대화에 참여하는 장면
- 발화별 화자를 구분할 수 있는 장면
- 발화의 순서와 영상 내 시점을 확인할 수 있는 장면
- 감정 점수의 변화가 대화 흐름에 따라 관찰될 가능성이 있는 장면
- 영상과 감정 분석 결과를 연결하여 보여주기에 적합한 장면

최종 선정 결과는 `scene_selection.csv`에 기록한다.

## 3. Audio Data Preparation

선정된 장면에서 발화별 음성 데이터를 준비한다.

### 3.1 Utterance Segmentation

- 대화 장면을 발화 단위로 구분한다.
- 각 발화의 시작 시간과 종료 시간을 기록한다.
- 발화별 음성 데이터를 모델 입력에 사용할 수 있도록 준비한다.

### 3.2 Speaker Identification

- 각 발화를 말한 화자를 확인한다.
- 발화와 화자 정보를 연결한다.
- 화자 정보가 불분명하거나 발화가 겹치는 구간은 별도로 검수한다.

### 3.3 Emotion Score Extraction

- 발화별 음성 데이터를 감정 분석 모델에 입력한다.
- 각 발화에 대한 Valence, Arousal, Dominance(VAD) 점수를 추출한다.
- 추출된 점수를 해당 발화의 시간 및 화자 정보와 연결한다.

## 4. Data Structure

시연 데이터는 다음과 같은 형태로 정리한다.

| Field | Description |
|---|---|
| scene_id | 장면 식별 번호 |
| start_time | 발화 시작 시간 |
| end_time | 발화 종료 시간 |
| speaker_id | 화자 식별 정보 |
| utterance | 발화 내용 |
| valence | 긍정·부정 감정 차원 점수 |
| arousal | 감정의 활성화 정도 점수 |
| dominance | 감정의 통제·주도 정도 점수 |

각 발화의 시간, 화자, 발화 내용, 감정 점수가 서로 올바르게 연결되도록 관리한다.

## 5. Data Validation

시연에 사용하기 전 다음 항목을 검수한다.

- 영상의 발화 시점과 기록된 시작·종료 시간이 일치하는가?
- 발화 내용과 화자 정보가 올바르게 연결되어 있는가?
- 모델의 감정 점수가 해당 발화에 정확히 연결되어 있는가?
- 발화 순서가 실제 영상의 대화 순서와 일치하는가?
- 발화가 겹치거나 화자 구분이 어려운 구간은 별도로 표시했는가?

데이터 검수 이후 영상, 화자 정보, 감정 점수 및 그래프를 연결하여 최종 시연 데이터를 확정한다.

## 6. Expected Output

최종적으로 영상 재생 시점에 맞춰 다음 정보를 확인할 수 있는 데이터를 구축한다.

- 현재 발화자의 정보
- 현재 발화 내용
- 발화별 VAD 감정 점수
- 대화 흐름에 따른 화자별 감정 변화

*Note: 실제 장면 선정 결과, 데이터 검수 결과 및 모델 출력값은 데이터 준비가 완료된 후 업데이트한다.*
