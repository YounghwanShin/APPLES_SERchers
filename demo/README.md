# Demo

## 1. Overview

본 프로젝트의 시연은 미국 드라마 *Friends*의 대화 장면을 활용하여 화자별 감정 점수와 대화 과정에서 나타나는 감정 변화를 시각적으로 보여주는 것을 목표로 한다.

음성 데이터를 모델에 입력하여 발화별 감정 점수를 추출하고, 이를 영상의 재생 시점 및 화자 정보와 연결한다.

최종 시연엔 사람이 VAD 점수를 평가해서 모델과 비교하기..?
## 2. Demo Process

1. 프렌즈 시연 후보 장면 10개 선정
2. 발화별 음성 추출 및 감정 점수 예측
3. 영상 시간, 화자, 발화 내용, 감정 점수 연결
4. 데이터 검수 및 최종 시연 장면 선정
5. 화자 간 감정 변화 분석
6. 영상과 감정 분석 결과를 연결한 시연 화면 구현

## 3. Main Features

- 프렌즈 영상 재생
- 현재 발화의 화자 및 발화 내용 표시
- 발화별 감정 점수 표시
- 화자 간 감정 변화 비교

## 4. Expected Demo Output

영상 재생 시점에 맞춰 현재 발화자의 감정 점수와 감정 변화 표시되는 시연 화면을 구현한다.
