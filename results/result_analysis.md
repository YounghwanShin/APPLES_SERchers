## Results
이 폴더는 감정 예측 모델의 실험 결과와 성능 평가 및 분석 내용을 저장하는 공간이다. 

# 1. Evaluation Metrics
모델의 예측 성능을 평가하기 위해 다음 지표를 사용한다. 
* RMSE (평균 제곱근 오차): 실제값과 예측값 사이의 오차 크기를 측정한다. (값이 낮을수록 예측 성능이 좋다)
* CCC (일치 상관 계수): 실제값과 예측값이 얼마나 일치하는지를 측정한다. (1에 가까울수록 일치도가 높다)

# 2. Model Comparison 
서로 다른 감정 정보를 입력으로 사용하는 세 가지 모델을 비교한다. 

# 3. Prediction Analysis
실제 감정과 모델이 예측한 감정을 비교하고, 예측이 성공하거나 실패한 사례를 분석한다. 

* 전체 예측 결과
* 예측 성공 사례 및 특징
* 예측 실패 사례 및 원인
* 모델별 성능 차이


# 4. Result Interpretation 
실험 결과를 바탕으로 다음 내용을 분석합니다. 

* 가장 높은 예측 성능을 보인 모델
* 상대방의 감정 정보가 예측에 미치는 영향
* 감정 차원별 예측 성능의 차이
* 모델 한계와 개선 가능성
